📚 VOCABULARY

Bar Graph: A graphical representation that uses rectangular bars to show comparisons among categories. The length of each bar represents the value or frequency of that category.

Box Plot: A graphical representation that displays the distribution of a data set through five-number summaries: minimum, first quartile (Q1), median, third quartile (Q3), and maximum.

Categorical Data: Data that consists of categories or groups, such as colors, types, or names, and cannot be measured numerically.

Circle Graph: A graphical representation, also known as a pie chart, that shows parts of a whole as slices of a circle, with each slice representing a percentage of the total.

Data Set: A collection of numbers or values that represent information.

Graphical Representation: A visual way of showing data using charts, graphs, or plots to make it easier to understand and analyze.

Histogram: A graphical representation that uses bars to show the frequency of numerical data within specific intervals, often used to display the distribution of continuous data.

Line Plot: A graphical representation that displays data along a number line, using Xs or dots to show frequency.

Measures of Center: Values that describe the middle of a data set, including mean (average), median (middle value), and mode (most common value).

Measures of Variability: Values that describe how spread out data is, such as range (difference between highest and lowest values) and interquartile range (IQR, the range of the middle 50% of data).

Numerical Data: Data that consists of numbers and can be measured or counted, such as height, weight, or test scores.

Stem-and-Leaf Plot: A graphical representation that organizes numerical data by separating digits into stems (leading digits) and leaves (trailing digits), making it easy to see the distribution of values.

📋 REPRESENTATIONS FOR NUMERICAL DATA SETS

Understanding the purpose and use of each graphical representation, how to create each, and observing a situation and its graphical representation.

Line Plot

A line plot is used to display numerical data by placing Xs or dots above a number line to show how often each value occurs.

Box Plot

A box plot (or box-and-whisker plot) is used to display numerical data by showing how data is distributed using five key points: minimum, first quartile (Q1), median, third quartile (Q3), and maximum.

Purpose: To show frequency of individual values.

Data Type: Numerical

Shows frequency of occurrences and helps identify repeated values and clusters or gaps in data.

Shows the Mode and Range.

Good for comparing smaller data sets and showing if the data set has a tail or outliers creating a skewed set.

Purpose: To show the spread and distribution of a data set.

Data Type: Numerical

Shows the range, quartiles, and median.

Can be used to identify symmetry, skewness, or outliers.

Good for comparing multiple data sets and larger data sets.

Creating a Line Plot:

  1. Draw a number line that covers the range of values.
  2. Place an "X" above each data value for every occurrence.
  3. Ensure the number of Xs matches the frequency of each value.
  4. Give the plot a Title.
  5. Label the number line.

Box Plot:

  1. Find the five-number summary (minimum, Q1, median, Q3, maximum).
  2. Draw a number line that covers the range of values.
  3. Plot a point to represent each of the 5 numbers in the summary.
  4. Draw a box from Q1 to Q3 with a vertical line at the median.
  5. Extend "whiskers" from the box to the minimum and maximum values.
  6. Give the plot a title.
  7. Label the number line.

Stem-and-Leaf Plot

A stem-and-leaf plot organizes numerical data by separating values into stems (tens) and leaves (ones), making it easy to see individual values and distribution.

Histogram

A histogram is used to display numerical data by grouping values into intervals and showing how often values fall within each interval using bars.

Purpose: To organize and display numerical data in a structured way.

Data Type: Numerical

Shows the distribution of values and individual values in data set.

Can be used to reveal clusters, gaps, and skewness (but not as clearly as a boxplot or histogram).

Can be used to calculate the mean, median, mode, and range.

Purpose: To show the distribution of continuous data over intervals.

Data Type: Numerical

Shows the frequency of distribution.

Can be used to identify peaks, gaps, and spread of data.

Good for comparing distributions of large data sets.

Shows skewness and tails, but does not highlight exact outliers.

Stem-and-Leaf Plot:

  1. Divide each data value into a stem (leading digits) and a leaf (last digit).
  2. List stems in order in a left column.
  3. Write the leaves in ascending order next to their corresponding stem.
  4. Provide a key.
  5. Give the plot a title.

Histogram:

  1. Create equal-sized intervals for the data range.
  2. Count how many data points fall into each interval.
  3. Draw bars representing the frequency of data points in each interval.
  4. Label the vertical axis as frequency and label the horizontal axis.
  5. Give the plot a title.

📋 REPRESENTATIONS FOR CATEGORICAL DATA SETS

Understanding the purpose and use of each categorical graphical representation, how to create each, and observing a situation and its graphical representation.

Circle Graph (Pie Chart)

A circle graph is used to display categorical data as parts of a whole, with each category represented as a slice of a circle.

Bar Graph

A bar graph is used to display categorical data by using bars to represent different categories and their frequencies.

Purpose: To show the proportions of categories in a whole.

Data Type: Categorical

Shows the percentage breakdown of the population in categories.

Highlights the largest and smallest categories.

Not great for comparing multiple data sets, but can compare two subgroups.

Does not show skewness or outliers.

Purpose: To compare categories in a set.

Data Type: Categorical

Helps compare different categories. Can also compare subgroups in those categories.

Identifies highest and lowest categories.

Shows the mode or most common category.

Great for comparing multiple data sets.

Does not show skewness or outliers.

How to Create a Circle Graph (Pie Chart)

  • Step 1: Collect categorical data and total the values.
  • Step 2: Convert each category’s value into a percentage of the total.
  • Step 3: Draw a circle and divide it into slices based on the percentages.
  • Step 4: Label each section with the category name and percentage.
  • Step 5: Title the graph to describe what it represents.

How to Create a Bar Chart

  • Step 1: Collect categorical data and total the values.
  • Step 2: Draw a horizontal or vertical axis with category names.
  • Step 3: Use bars to represent the number of occurrences in each category.
  • Step 4: Label the axes with category names and numerical values.
  • Step 5: Title the graph to describe what it represents.

Conclusion

Each type of graph has a specific purpose and helps us visualize data in different ways. Some graphs, like bar graphs and circle graphs, are best for comparing categories, while others, like histograms and box plots, help us analyze numerical data distributions and detect trends. Understanding which graph to use will help you interpret data correctly, make predictions, and draw meaningful conclusions. Keep practicing, and soon you'll become skilled at choosing and analyzing the right graph for any data set!
